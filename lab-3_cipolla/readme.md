# Лабораторная работа №3
## Вычисление квадратного корня в поле посредством вероятностного алгоритма Чиполлы

Требуестся `Go` версии `1.24.3` и выше.

Проект реализует алгоритм вычисления квадратного корня в конечном поле с использованием вероятностного алгоритма Чиполлы

Точка входа для запуска программы располагается в `/cmd`:
```bash
go run lab-3_cipolla/cmd/main.go
```

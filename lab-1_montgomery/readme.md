# Лабораторная работа №1
## Алгоритм Монтгомери умножения и возведения в степень

Требуестся `Go` версии `1.24.3` и выше.

Проект реализует алгоритмы умножения и возведения в степень в конечном кольце вычетов по модулю большого натурального числа (вкладка montgomery), также для практики были реализованы алгоритмы работы с целыми числами произвольной точности (вкладка MPI, аналог BigInt).

Были реализованы прямое (`Phi`) и обратное к нему (`InversePhi`) преобразования, алгоритм Redc, приводящий числа произвольной точности в Монтгомери-форму, а также функции умножения/экспоненциирования чисел как в Монтгомери форме и обертки для них.

Точки входа для запуска программы располагаются в `/cmd`:
1. Запуск демонстрации умножения: 
```bash
go run lab-1_montgomery/cmd/multiplication/main.go
```
2. Запуск демонстрации возведения в степень:
```bash
go run lab-1_montgomery/cmd/exponentiation/main.go
```
Демнострационные варианты предполагают ввод чисел в десятичной системе счисления и создания соответствующих чисел с произвольной точностью по основанию 10, однако проект должен поддерживать любое основание системы счисления вплоть до размера uint64 = 2^64-1.

Также были написаны тесты на данных, предоставленных в соответствующих главах книги `Handbook of Elliptic and Hyperelliptic Curve Cryptography`.
